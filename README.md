## 關於我

我是來自台灣的軟體工程師。我喜歡親手實作，從底層理解技術原理。目前的興趣集中在以下幾個方向：

- **電腦視覺與影像處理**：以 C 語言手刻基本影像演算法，並讓它能在樹莓派等邊緣裝置上執行。
- **深度學習**：用 PyTorch 訓練與壓縮小型模型。
- **AI Agent**：實作工具呼叫、權限控制等能力，並串接本地端或雲端的大型語言模型。
- **個人工具與作品集**：開發可以實際使用的小型網頁應用程式。
