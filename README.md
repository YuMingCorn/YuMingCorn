## 關於我

我是來自台灣的軟體工程師，喜歡深度學習與 AI 相關技術，也喜歡從底層理解技術原理。目前的興趣集中在以下幾個方向：

- **電腦視覺與影像處理**：以 C 語言手刻基本影像演算法，讓它們能在樹莓派等運算資源有限的邊緣裝置上執行。我也希望把這些演算法整理成好用的函式庫，讓開發者能直接編譯進自己的專案。
- **深度學習**：用 PyTorch 訓練與壓縮小型模型，並有使用 TensorRT、ONNX、NCNN 將模型部署到邊緣裝置的經驗。
- **AI Agent**：實作工具呼叫、權限控制等能力，並串接本地端或雲端的大型語言模型。這部分我仍在持續精進。
- **個人工具與作品集**：開發能在日常生活中實際使用的小型網頁應用程式。
