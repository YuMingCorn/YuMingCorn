## 關於我

我是來自台灣的軟體工程師。喜歡深度學與 AI 相關技術，從底層理解技術原理。目前的興趣集中在以下幾個方向：

- **電腦視覺與影像處理**：以 C 語言手刻基本影像演算法，並讓它能在樹莓派等邊緣裝置上執行，這對於邊緣端缺少運算資源很重要，且需要有更好的 Library 幫助程式設計師更方便的編譯進去
- **深度學習**：用 PyTorch 訓練與壓縮小型模型，並有在邊緣端裝置透過 tensorRT、ONNX、NCNN 部屬模型經驗
- **AI Agent**：實作工具呼叫、權限控制等能力，並串接本地端或雲端的大型語言模型，這部分持續精進
- **個人工具與作品集**：開發可以實際使用的小型網頁應用程式
